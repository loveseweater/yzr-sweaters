## 快速上手

### 改社媒主页简介
打开 `2_社媒简介与关键词.md`，复制对应平台的英文简介 + 关键词，粘贴到社媒主页的 Bio 框。

### 发引流帖
打开 `3_发帖引流文案.md`，选一套模板 → 复制英文 → **配一张产品图**（在 `../images/` 里挑）→ 带上链接 `https://yzrsweaters.com` → 发布。

### 改平台名字
打开 `4_平台改名指引.md`，按 Facebook / IG / LinkedIn / TikTok / Pinterest / X 的步骤，把显示名改成 `Daniel Liu`。

### 写开发信
打开 `5_开发信模板与邮件签名.md`，里面有按客户类型分的开发信模板 + 统一英文签名。

### 查网站信息
打开 `1_网站信息总览.md`，公司全称、官网、邮箱、WhatsApp、产品线、话术全有。

## 技术文件说明（英文，不要改）

网站能正常打开依赖这些**英文路径**，请勿重命名：

- `index.html` `products.html` `about.html` `contact.html` `capabilities.html` `product.html` `blog.html` —— 网页
- `blog/` —— 博客文章
- `images/` `css/` —— 图片和样式
- `admin/` —— 内容管理后台（`server.js` + `manage.html`）
- `sitemap.xml` `robots.txt` `products.json` —— 站点数据

> 这些如果改成中文，网站会打不开。
