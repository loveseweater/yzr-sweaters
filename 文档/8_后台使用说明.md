# YZR Sweaters 内容管理后台 —— 使用说明

这个后台让你**不用懂代码**，就能自己更新网站的产品和内容，改完会自动发布上线。

> ⚠️ 重要说明：目前网站是**静态站（托管在 Cloudflare Pages）**，没有真正的服务器/数据库。所以这个后台是"**本地内容管理工具**"——你在自己电脑上运行它，编辑内容、一键发布，它能自动帮你提交到 GitHub，Cloudflare 随即自动重新上线。等以后客户多了，我们可以再升级成"在线登录后台"（需要接服务器/数据库）。

---

## 一、怎么打开后台（每次操作前）

1. 打开电脑的**终端**（Git Bash 或 CMD）。如果你用 ZCode 环境，直接在对应目录操作。
2. 进入网站目录：
   ```
   cd G:\来发信开发客户\landing-page
   ```
3. 启动后台：
   ```
   node admin/server.js
   ```
4. 看到 `Admin running: http://127.0.0.1:8090` 就是成功了。
5. **用浏览器打开**：
   ```
   http://127.0.0.1:8090
   ```
   就能看到管理界面。

> 用完关掉终端窗口即可停止后台。

---

## 二、后台界面能做什么

管理界面有这几个部分：

| 区域 | 作用 |
|------|------|
| **产品分类** | 显示当前所有产品分类（毛衣、开衫、针织裙、围巾、帽子、手套、腿套等） |
| **添加/编辑产品** | 填产品名称、选分类、填图片路径、填描述、填标签，点「添加/更新产品」 |
| **现有产品** | 列出所有产品，每个可「编辑」或「删除」 |
| **保存（仅本地）** | 只保存到本地文件，不发布 |
| **保存并发布上线** | 保存 + 自动提交 GitHub + 触发 Cloudflare 重新发布（约1分钟生效） |

### 添加产品步骤
1. 在「产品名称」填名字（如 `Chunky Knit Scarf — Camel`）
2. 「分类」选它属于哪类（围巾、帽子、手套…）
3. 「产品图片」填图片路径（`/images/xxx.jpg`，图片要放进网站 images 目录）
4. 「产品描述」填一句话介绍
5. 「标签」填几个词，逗号分隔（如 `unisex, winter, chunky`）
6. 点「**添加/更新产品**」
7. 点「**保存并发布上线**」

这样产品就会出现在 `https://yzrsweaters.com/products` 页面，约1分钟后上线。

> 想新增一个新**分类**（比如「Knitted Blankets」）？目前分类在 `products.json` 里定义，你可以让我帮你加，或在 manage 界面会随 JSON 自动显示。

## 三、怎么新增博客文章

博客文章目前是**独立 HTML 文件**（在 `blog/` 目录）。在后台里**暂时还不能直接新建文章文件**（因为要生成完整 HTML 页面）。要做新文章：
- 最省事：把你**写好的文章文字/图片**给我，或找我来帮你生成新的文章 HTML 页面（我可以按你给的标题、正文、图片，生成一篇文章页，并自动加到博客列表和 sitemap）。
- 之后我会把"发文章"也做进后台，让你像加产品一样简单。

## 四、评论功能

文章的评论区我已经加好了挂载点，但**要真正显示留言，需要配置 GitHub Discussions**（Giscus 评论系统基于 GitHub，免费、能真正留言）。配置比较简单，需要：
1. 在 GitHub 你的仓库开启 **Discussions**（Settings → Features → 勾选 Discussions）
2. 安装 **Giscus App** 到你的仓库
3. 把 Giscus 给的配置（repo、repoId、category 等）填给我

我可以帮你把这步搞定，配好后你的文章就能让客户真正留言评论了。

## 五、阅读量 & 访问量统计

- **阅读量**：每篇文章顶部已经显示"Views: 数字"，会记录本地浏览量（目前是本地计数，访客端刷新+1，同一个浏览器会累计）。
- **全站访问量**：我已经在所有页面埋了两套统计脚本：
  - **GoatCounter**（免费、无需后端，能统计真实访问量 PV/独立访客）—— 需要你**注册一个 GoatCounter 账号**，把 site code 填进去。注册很简单，去 goatcounter.com 用邮箱注册即可。注册后我可以把 code 换上，就能看到真实的访客数了。

## 六、确认发布成功的提示

点「保存并发布上线」后，页面会显示：
```
[发布] saved + pushed to GitHub (Cloudflare deploy started)
```
大约 1 分钟后，刷新你的官网就能看到更新。

## 以后要升级（客户多了）

等你的业务起来、需要真正的在线后台（登录网址就能改、实时保存、后台看所有数据），我们就**升级成带服务器/数据库的版本**（Cloudflare Workers + D1，或换独立服务器）。那时代码和数据都能迁移，不用担心。

现在先这样用起来，完全够你日常更新产品。
