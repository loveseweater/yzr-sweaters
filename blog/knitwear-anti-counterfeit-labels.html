Anti-Counterfeit Labels for Knitwear: Holograms, QR Codes and Serialisation

By YZR Sweaters · 2026-11

Quick answer

Most anti-counterfeit measures on knitwear are applied at the trim stage, not in the knitting. The practical options are a holographic or tamper-evident hangtag, a unique QR or serial code per garment that a customer can verify, a woven label with a security feature, and plain consistency — matching the label, barcode and packing records to the style. Each stops a different problem: a hologram raises the cost of a casual copy, a serialised code lets you spot a duplicated or diverted batch, and clean records make a marketplace takedown possible. None of it replaces a registered trademark.

We see this a lot once a style starts selling well on marketplaces: the buyer wants to "add anti-counterfeit" to the next order, and the request arrives as a single line on the tech pack. There is no single thing to add. There are several, they are applied by different suppliers at different stages, and they protect against different problems. Here is what a knitwear factory can actually do, and where the work belongs on your side.

Start with what you are protecting

Three different problems get called counterfeiting. A third party copies your design and sells a lookalike under their own name — that is a design and trademark question, covered in protecting your knitwear designs. Someone puts your label on a garment you never made, which is where authentication features help. Or genuine production leaks out of the supply chain as an unauthorised overrun, which is a subcontracting and production control problem. A hologram does nothing about the first, a serial number does nothing about the third unless you control the code list, and no label fixes a missing trademark. Decide which one you have before specifying anything.

Holograms and tamper-evident hangtags

This is the most common first step because it is easy to apply. A holographic sticker or patch goes on the hangtag, or a tamper-evident seal closes the polybag. Unit cost is small, but there is usually a minimum order from the security printer and the artwork file has to be supplied and approved — which means it belongs on the trim card early, not two weeks before packing. A hologram raises the cost and difficulty of a casual copy and gives customers something visible to look for. It does not authenticate an individual garment, and determined copiers can buy convincing generic holograms. Treat it as a deterrent, not a database. Our trims and hangtags guide covers how these items are specified and costed.

QR codes and serialisation

A unique code per garment is the option that actually lets you verify a unit. The factory prints or weaves the code, you run the landing page and database behind it, and a customer scans to check that the code exists and has not been queried hundreds of times. What we need from the brand is a code list or a defined range per carton, in a format our packing team can work with, plus a clear rule for what happens to unused codes. The packing list then has to map codes to cartons — that record is what makes a diverted batch visible later. See the export document pack for where that mapping sits, and barcodes and GTINs for the difference between a style-level code and a unit-level one. Where retail customers require it, RFID carries a similar idea at item level with different hardware.

The honest limitation: a copied QR code still resolves to your page. What you gain is the ability to see duplicates and to give customers a reason to trust the channel they bought from, not an invisible shield.

Security features in a sewn-in label

If the feature is on the garment rather than the hangtag, it has to survive the life of the product. Custom weave structures, microtext, UV-reactive thread or heat-sensitive ink can all go into a woven label, but each adds cost and lead time, and each has to be checked against wash durability — our label durability guide covers what happens to labels in the wash. It also has to stay compliant: the sewn-in label is a legal document carrying fibre composition, origin and care instructions, so security artwork cannot crowd out the required text. Care labelling rules set out what must be there, and trim card approval is where both requirements get signed off together.

What the factory can and cannot do

We can apply buyer-supplied secure trims under a free-issue arrangement, keep code lists matched to cartons, segregate and account for overruns, hold a gold seal sample that proves exactly what was approved, and support the traceability records behind a claim. We can sign a confidentiality agreement and welcome an factory audit. What we cannot do is run your verification database, register your trademark or police marketplaces — those are brand-side jobs, and a label without them is just a sticker. Be careful about who holds the security artwork and the code list; the brand should.

A sensible first-order setup

For a first run, we would suggest something proportionate: a registered mark, one consistent label and barcode set, a single serialised QR hangtag, and a code-to-carton record kept with the packing documents. Approve it on the trim card at the same time as the care label, add the security printer's lead time to the production schedule, and test that a scanned code resolves before the container is packed — our packing guide covers where the hangtag is attached. That catches most of the real problems without turning a 500-piece first order into a systems project. Add holograms or RFID later, when the volume justifies the cost.

Frequently asked questions

Will a QR code stop counterfeiting?

Not on its own. A copied code still resolves to your page, so it is a verification and detection tool rather than a barrier. Its value is that duplicated codes, diverted batches and suspicious query patterns become visible, and customers get a way to check a garment. The database and the response to a hit sit with the brand.

Can YZR supply the hologram or security labels?

We can apply buyer-supplied secure trims and coordinate with your security printer on attachment, quantities and carton mapping. The security artwork, the code list and the supplier relationship should stay with the brand so the feature is not reproducible from a factory order alone. Approve the items on the trim card with the care label.

Does a security label need to survive washing?

Only if it is sewn into the garment. A hangtag or polybag seal is removed before use, so wash durability is not a question there. A woven label with security features must survive the wash and must still leave room for the legally required fibre, origin and care text — check both at trim card approval.
