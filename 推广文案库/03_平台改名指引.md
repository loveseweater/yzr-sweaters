# 各社媒平台改名成为「Daniel Liu」操作指引

> 目标：把各平台的**显示名（Display name）**统一改成 **Daniel Liu**，整体一致、专业。
> 显示名可以放心改，**不影响已经发布的任何链接**。@用户名(handle) 可以不改，让现有链接继续有效。

---

## 一、Facebook 主页（你重点关注的那个）

你发的 Facebook 主页是 `lovesweatercom`。把它的**主页名称**改成含 Daniel Liu：

### 操作步骤
1. 登录 Facebook，进入你的主页（`https://www.facebook.com/lovesweatercom/`）。
2. 点右上角**你的头像** → 选「**主页**」。
3. 在主页上点「**关于 / About**」（左侧菜单或主页简介旁）。
4. 点「**编辑主页信息 / Edit Page Info**」。
5. 找到「**名称 / Name**」栏，点编辑，输入新名称（建议见下）。
6. 点「保存」。
7. **注意**：Facebook 有时会要求确认，或提示"名称更改需审核"，按提示提交即可（可能需要几小时到1天审核）。

### 建议的主页名称
```
Daniel Liu · YZR Sweaters
```
> 如果你的主页是「品牌/商业主页」，名称里带 `·` 或 `-` 可能会被 Facebook 限制。如果带符号被拒，就用：
> `Daniel Liu YZR Sweaters`（用空格分隔）或直接 `Daniel Liu`。

### 如果主页改成个人名被限制了
Facebook 对**商业主页、专页**的名称有限制（不能随便改成纯个人名）。如果你这个主页是**专页（Page）**，可能：
- 只能把 **「用户名/链接」** 改，或
- 名称里保留品牌词，比如 `Daniel Liu - YZR Sweaters`

遇到限制就截图发我，我帮你想合规的写法。

## 二、Instagram
1. 打开 IG App → 点右下角我的头像 → 进个人主页。
2. 点「**编辑个人资料 / Edit profile**」。
3. 在「**名称 / Name**」栏填：`Daniel Liu`。
4. 点右上角「完成」。
> 「名称」≠「用户名(@)」。改名称不影响你的 @yzrcashmere 链接。

---

## 三、LinkedIn（个人资料）
1. 进 LinkedIn → 点右上角头像 →「查看个人资料」。
2. 点资料卡右上角「**编辑 / Edit**」（铅笔图标）。
3. 在「**名字 First name**」填 `Daniel`，「**姓氏 Last name**」填 `Liu`。
4. 保存。
> 可以把「头衔 / Headline」改成：`Knitwear Manufacturer | OEM/ODM Sweaters | YZR Sweaters`

---

## 四、TikTok
1. 进 TikTok → 右下角「个人主页」→「编辑资料」。
2. 「**名字 / Name**」填：`Daniel Liu`。
3. 保存。
> 不改 @ 用户名即可。

---

## 五、Pinterest
1. 进 Pinterest → 右上角头像 →「设置」。
2. 点「**个人资料 / Profile**」。
3. 「**名字 / Name**」填：`Daniel Liu`。
4. 保存。

---

## 六、X / Twitter（如适用）
1. 进 X → 左上角头像 →「设置与隐私」。
2. 「**头像 / Profile**」→「**名称 / Name**」填：`Daniel Liu`。
3. 保存。

---

## 统一后的效果
所有平台显示名都变成 **Daniel Liu**，+ 每个简介里都带 `https://yzrsweaters.com`，风格统一、专业、好记。客户在任何平台看到你都是同一个名字，信任感更强。
