# YZR Sweaters —— 推广文案库

> 这里是网站 + 推广引流用到的**全部文案和资料**，拿来就能发。按需打开对应文件。

## 文件清单

| 文件 | 内容 | 什么时候用 |
|------|------|-----------|
| `00_总览与网站信息.md` | 公司信息、官网、联系方式、产品、目标客户、询盘话术 | 填资料、回客户、了解全貌 |
| `01_社媒简介文案.md` | 各平台主页简介 Bio（Facebook/IG/LinkedIn/TikTok/Pinterest/X） | 改社媒主页简介 |
| `02_发帖引流文案.md` | 10 套发帖模板（产品/定制/工厂/询价/干货） | 发帖、引流、带链接 |

## 快速上手

### 改社媒主页简介
打开 `01_社媒简介文案.md`，复制对应平台的英文简介，粘贴到社媒主页的 Bio 框。

### 发引流帖
打开 `02_发帖引流文案.md`，选一套模板 → 复制英文 → **配一张产品图**（在 `../images/` 里挑）→ 带上链接 `https://yzrsweaters.com` → 发布。

### 需要的信息都在这
打开 `00_总览与网站信息.md`，公司全称、官网、邮箱、WhatsApp、产品线、话术全有。
